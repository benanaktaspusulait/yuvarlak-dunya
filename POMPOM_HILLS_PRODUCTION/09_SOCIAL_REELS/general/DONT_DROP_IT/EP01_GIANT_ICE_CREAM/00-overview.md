# DON'T DROP IT! — EP01: Giant Ice Cream

> **TEST FORMAT — Universal Audience Shorts**
> Bu format mevcut preschool Shorts'lardan farklıdır.
> Amaç: Genel kitle Shorts/Reels feed'inde organik erişim testi.
> Hipotez: OLAY → merak → komedi/payoff → Pompom sıralaması,
> mevcut Pompom → çocuk hikâyesi → İngilizce/eğitim → olay tersini dener.

---

## Format Bilgisi

| Alan | Değer |
|------|-------|
| Format adı | DON'T DROP IT! |
| Tür | Fiziksel komedi / micro gag |
| Süre | 9–12 saniye |
| Format | 9:16 dikey, 1080×1920, 24 fps |
| Mod | Frame-to-video, tek continuous shot |
| Üretim | OpenArt |
| Dil | Minimal — sesi kapalı izlenebilir |
| Karakter | Kiko + Opa |
| Lokasyon | Central Square |
| Hedef kitle | Genel Shorts/Reels izleyicisi (yetişkin dahil) |

---

## Hipotez

Mevcut Pompom videoları feed'de "preschool English / children's story" olarak
etiketleniyor → yetişkin izleyici ilk saniyede geçiyor.

Bu test: Video açıldığında izleyici "bu düşecek" hissini almalı → merak → payoff →
sonra karakterlerin Pompom Hills olduğunu fark etmeli.

**Sıralama:** OLAY → merak → komedi/payoff → Pompom

---

## Hikâye Özeti

Kiko, kendisinden neredeyse büyük, üst üste dizilmiş dev bir dondurma taşır.
Dondurma tehlikeli biçimde yana yatmıştır. En üst top düşer, Kiko yakalayamaz,
Opa kadraja girer, top Opa'nın kafasına/şapkasına oturur. Kiko güler, Opa
"My ice cream?" der. Top tekrar kaymaya başlar → LOOP.
